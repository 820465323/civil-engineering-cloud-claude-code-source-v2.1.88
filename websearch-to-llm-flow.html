③ web_search_tool_result 到达后的服务端后处理管道

📌 重要说明 当客户端代码（WebSearchTool.ts）收到 web_search_tool_result 块时， HTML 的抓取与 DOM 解析已由 Anthropic 服务器端完成。 客户端仅接收到结构化的搜索结果（title、url、snippet 等字段），不会直接处理原始 HTML。 以下是服务端的典型后处理步骤。
步骤 1

🌐 获取 HTML

服务端对搜索引擎返回的每个 URL 发起 HTTP 请求，获取目标页面的原始 HTML 内容。

步骤 2

🧹 HTML 清洗

去除 <script>、<style>、广告 iframe、导航栏、侧边栏等噪音节点，进行字符集标准化（UTF-8）。

步骤 3

📄 提取主内容

使用正文抽取算法（Readability/jusText/boilerpipe 类），识别最大连续文本块或语义 <article> 标签，提取核心正文。

步骤 4

✂️ 分块（Chunking）

将长文本按语义边界（段落、句子）切分为固定 token 上限的片段，便于后续嵌入与检索。

步骤 5

🔢 向量嵌入与索引

对每个文本块生成稠密向量（embedding），建立近似最近邻索引，供相关性检索使用。

步骤 6

🏆 相关性排序

计算查询向量与文档块向量的余弦相似度，结合 BM25/reranker 等方法，筛选最相关的 top-K 片段。

步骤 7

📝 组合最终摘要

将 top-K 片段与元数据（title、url）拼接，构成传给 LLM 的上下文；服务端将此内容封装为 web_search_tool_result 块流式回送给客户端。

步骤 8

📩 回送客户端

服务端以 SSE/流式方式将 web_search_tool_result 块推送回客户端，客户端 makeOutputFromSearchResponse 解析 title 和 url，组装 tool_result 供 LLM 生成最终回答。

⚙️ 客户端可见内容 WebSearchTool.ts 中 makeOutputFromSearchResponse（lines 86-150）只能访问 web_search_tool_result 块中的 title 和 url 字段。 正文内容、snippet、ranking 分数等均已在服务端处理完毕，客户端仅获得结构化链接列表及 LLM 生成的文本摘要。

⑤ 限制与隐私 / Robots 注意事项

🌍 地域与模型限制

仅限美国地区 Web Search 功能目前仅在美国地区可用（prompt.ts："Web search is only available in the US"）。 非美国地区的请求将无法触发搜索。
Provider 限制 仅以下 API 提供商支持（isEnabled() lines 168-193）：
  • firstParty（Anthropic 官方 API）：无条件启用
  • Vertex AI：仅支持 Claude Opus 4 / Sonnet 4 / Haiku 4 及以上
  • Foundry：无条件启用（仅部署兼容模型）
  • 其他 provider（如 Bedrock、自定义端点）：不支持
单次调用上限 每次 WebSearchTool 调用最多执行 8 次独立搜索（makeToolSchema line 82: max_uses: 8）。

🔒 隐私与安全

查询内容泄露风险 用户的查询关键词会通过 Anthropic API 发送至搜索引擎。请避免在查询中包含：
  • 个人身份信息（姓名、身份证、手机号等）
  • 企业内部机密信息
  • 密码或密钥
域名过滤 可通过 allowed_domains 和 blocked_domains 参数控制搜索范围，但两者不能同时使用。

🤖 Robots.txt 与爬取礼仪

服务端遵守 robots.txt Anthropic 服务端在抓取 URL 内容时，应（且通常会）遵守目标站点的 robots.txt 规则。 若某站点禁止爬虫，该页面内容将不会被处理或返回给客户端。
  • 使用 blocked_domains 可主动排除不希望被访问的域名
  • 频繁对同一域名发起大量搜索请求，可能导致 IP 被该站点暂时封禁
  • 部分网站需要 JavaScript 渲染，服务端静态抓取可能内容不完整

📊 数据准确性限制

时效性 搜索结果受搜索引擎索引延迟影响，最新事件（几分钟内）可能无法检索到。 getWebSearchPrompt() 会注入当前月份年份，以帮助 LLM 构造更精准的查询。
内容可靠性 搜索结果来源于互联网公开内容，LLM 的摘要可能包含错误信息。 代码强制要求在回答中包含 Sources 超链接（mapToolResultToToolResultBlockParam line 427）， 用户应自行核实来源。
无秘密注入 本工具代码中不包含任何 API key、搜索引擎订阅密钥或私有令牌。 所有认证通过 Anthropic SDK 标准授权机制处理，密钥由运行环境注入，不在代码中硬编码。
